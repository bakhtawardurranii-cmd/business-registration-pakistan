Trademark classes in Pakistan: how to choose the right one

Pakistan uses the international Nice Classification, which has 45 classes: 1 to 34 for goods and 35 to 45 for services. Your trademark protects only the class or classes you file in, so choose the ones that describe what you actually sell.

How do the 45 trademark classes work?

Each class groups similar goods or services. Each application covers one class. If you sell clothing and run a retail shop, you may need class 25 and class 35.

What if you choose the wrong class?

A mark registered in the wrong class does not protect your real business, and correcting it usually means a new application and new fees. See trademark registration cost in Pakistan. Ask for help if your activity spans several classes.

How to describe your goods and services

List what you actually sell in plain words, for example "women's clothing" or "accounting software as a service". Avoid claiming goods you do not plan to sell. Broad claims invite objections and can be attacked later for non-use: see renewal and use rules.

Questions people ask about trademark classes

How many classes do I need?

One for each group of goods or services you want protected.

Can I add a class later?

Yes, by filing a new application for that class.

Is a software business class 9 or class 42?

Often both: class 9 for downloadable software and class 42 for software as a service.
