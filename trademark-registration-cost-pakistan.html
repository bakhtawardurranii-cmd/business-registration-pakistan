Common questions

Trademark cost, answered

How much does trademark registration cost in Pakistan?

IPO-Pakistan's official fees are roughly PKR 3,000 to file per class and PKR 9,000 for the final registration certificate per class. A consultant's service fee is typically separate.

Can I file one application to cover multiple classes?

No. Pakistan does not allow multi-class trademark applications, so a separate application and fee is required for each class you want to register in.

Is there a renewal fee for trademarks?

Yes. Trademarks must be renewed every 10 years, and IPO-Pakistan charges a separate renewal fee at that point.
