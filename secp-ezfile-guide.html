How to use SECP's eZfile portal.

eZfile is SECP’s online filing system for company registration and related filings, being progressively supplemented by the newer LEAP platform, but still used for a number of registration types.
Compare eZfile vs LEAP Let us file for you

Using the portal

What filing through eZfile involves

You'll need a registered eZfile account, a valid digital signature, and your incorporation documents ready as digital files. The portal walks through name reservation, document upload, and fee payment in sequence.

Most rejections happen because of incomplete or inconsistent documents — mismatched names between the MOA and the application form, for example. We handle the filing directly to avoid these back-and-forth delays.

Common questions

Answered

Is eZfile being phased out?

SECP has been progressively shifting new registrations toward the LEAP platform, though eZfile remains in use for a number of filing types at the time of writing.

Do I need any special software to use eZfile?

You'll need a compatible digital signature and a standard web browser — no special software installation is required beyond that.

What if my eZfile submission is rejected?

SECP typically provides a reason for rejection, and you can correct and resubmit through the same portal, though this adds time to your overall registration.
